# СopyApp (Android)

СopyApp — Android-приложение с интерфейсом управления VPN-подключением и конфигурациями.  
Проект ориентирован на демонстрацию работы с пользовательским UI, навигацией между экранами, интерактивными элементами и состояниями интерфейса без использования сложных архитектурных библиотек.

Приложение не выполняет реального сетевого подключения и предназначено для учебных и демонстрационных целей.

---

## 📱 Основные экраны

### 1. Главный экран (MainActivity)
- Отображение текущего состояния подключения
- Интерактивный слайдер для подключения
- Отображение статистики (память, загрузка, отправка)
- Переключатель системной опции
- Нижняя навигация (BottomNavigation)

📷 *Скриншот главного экрана:*  
`/docs/images/main_screen.png`

---

### 2. Экран конфигураций (ConfigActivity)
- Список конфигураций, сгруппированных в «папку»
- Сворачивание / разворачивание списка
- Выбор активной конфигурации
- Визуальное выделение выбранного конфига
- Отображение протокола (например, VLESS)
- Пинг сервера и адрес

## 🧩 Архитектура приложения

Приложение построено по **классической Android-архитектуре без MVVM**, что упрощает понимание логики и наглядно демонстрирует работу UI.

### Используемые компоненты:
- `Activity` — управление экранами
- `XML Layout` — разметка интерфейса
- `BottomNavigationView` — навигация
- `ScrollView + LinearLayout` — прокрутка контента
- `Handler + Runnable` — обновление данных
- `Drawable` ресурсы — кастомные элементы интерфейса

## 🔁 Навигация

Навигация между экранами реализована через `BottomNavigationView`:

- **Главная** → `MainActivity`
- **Конфигурации** → `ConfigActivity`

Переходы выполняются через `Intent` без анимаций, что создаёт ощущение переключения вкладок.

## 🎚 Основная логика

### Слайдер подключения
- Перетаскиваемый `thumb`
- Изменение цвета при достижении порога
- Фиксация положения при успешном подключении
- Автоматический запуск генерации статистики

### Выбор конфигурации
- Только **одна конфигурация может быть активна**
- При выборе:
  - предыдущая конфигурация сбрасывается
  - протокол отображается только у активной
  - карточка меняет размер и фон
