# 📱 SMS Analyzer (Android, Java)

## Описание проекта

Данное Android-приложение предназначено для считывания и анализа входящих SMS-сообщений пользователя. Приложение определяет операции зачисления и списания денежных средств на основе анализа текста сообщений и подсчитывает общие суммы доходов и расходов.

Основной акцент работы сделан на использовании **многопоточности** и взаимодействии с системными данными Android (SMS).

Приложение реализовано на языке **Java** в среде **Android Studio**.

## Работа с SMS

### Получение SMS

Считывание сообщений выполняется через системный API Android:
```
content://sms/inbox
```

Для доступа используется `ContentResolver` и `Cursor`.

> Ограничение количества сообщений (например, 30) введено для оптимизации и повышения производительности.

---

### Использование многопоточности

Чтение и анализ SMS выполняются в отдельном потоке (`Thread`).

**Причины:**
- Операция чтения SMS может быть ресурсоёмкой
- Выполнение в UI-потоке может привести к зависанию интерфейса

Обновление пользовательского интерфейса осуществляется через:
```java
runOnUiThread()
```

---

## Анализ текста сообщений

### Классификация SMS

Определение типа сообщения выполняется на основе ключевых слов:

**Зачисление:**
- «зачисление»
- «пополнение»
- «поступление»
- «+»

**Списание:**
- «списание»
- «оплата»
- «покупка»
- «-»

Анализ выполняется методом `contains()`.

---

### Извлечение суммы

Для поиска суммы используется регулярное выражение, извлекающее первое числовое значение из текста сообщения.

**Используется:** `Pattern` / `Matcher`

Полученное значение используется для расчёта итоговых сумм.

---

## Основные методы MainActivity

### `requestSmsPermission()`
Запрашивает у пользователя разрешение на чтение SMS (`READ_SMS`).

### `readSmsInBackground()`
- Запускает фоновый поток
- Считывает SMS
- Анализирует текст
- Подсчитывает суммы
- Формирует список для отображения

### `extractAmount(String text)`
Извлекает числовое значение (сумму) из текста SMS.

---

## Разрешения

Для работы приложения требуется разрешение:
```xml
<uses-permission android:name="android.permission.READ_SMS"/>
```

> Разрешение запрашивается динамически во время работы приложения.
