# Парковочная система с конечным автоматом (Android, Java)

## Описание проекта
Данный проект представляет собой мобильное Android-приложение, демонстрирующее работу конечного автомата на примере парковочной сессии.

Приложение разработано на языке **Java** в среде **Android Studio** и моделирует жизненный цикл парковки: от бронирования до завершения сессии и оплаты.

## Суть проекта
Основная задача проекта — показать применение **конечного автомата состояний** для управления логикой приложения.

Парковочная сессия может находиться только в одном состоянии в каждый момент времени, а переходы между состояниями возможны только при выполнении определённых условий.

## Состояния конечного автомата
В приложении используется конечный набор состояний:

- `FREE` — парковка свободна
- `RESERVED` — парковка забронирована
- `ACTIVE` — парковочная сессия начата
- `FINISHED` — сессия завершена
- `PAID` — парковка оплачена

Начальным состоянием автомата является `FREE`.

## События автомата
Переходы между состояниями происходят в ответ на следующие события:

- `RESERVE` — бронирование парковки
- `START_SESSION` — начало парковочной сессии
- `FINISH_SESSION` — завершение сессии
- `PAY` — оплата
- `RESET` — сброс состояния

## Реализация конечного автомата
Конечный автомат реализован в классе `ParkingStateMachine`.

### Основные элементы реализации:
- Текущее состояние хранится в поле `currentState`
- Состояния описаны с помощью перечисления `ParkingState`
- События автомата описаны в перечислении `ParkingEvent`
- Таблица переходов инициализируется в методе `initTransitions()`
- Переходы между состояниями обрабатываются универсальным методом `handleEvent(...)`

Такой подход соответствует классической модели конечного автомата и делает логику наглядной и расширяемой.

## Структура проекта
- `MainActivity.java` — пользовательский интерфейс и обработка действий пользователя
- `ParkingState.java` — описание состояний конечного автомата
- `ParkingEvent.java` — описание событий автомата
- `ParkingStateMachine.java` — логика конечного автомата и таблица переходов
- `activity_main.xml` — разметка пользовательского интерфейса

## Пользовательский интерфейс
Интерфейс приложения реализован в виде одного экрана с кнопками, каждая из которых соответствует событию конечного автомата.

Текущее состояние парковки отображается на экране в текстовом виде.  
При попытке недопустимого перехода пользователю выводится сообщение об ошибке.

## Преимущества выбранного подхода
- Чёткое разделение состояний и событий
- Исключение некорректных переходов
- Простота расширения логики
- Наглядное соответствие теории конечных автоматов

## Используемые технологии
- Java
- Android SDK
- Android Studio
- XML (разметка интерфейса)
