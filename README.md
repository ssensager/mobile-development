# ⏱️ Background Timer (Android, Java)

## Описание проекта

Данное Android-приложение реализует фоновый таймер с отображением прошедшего времени в пользовательском интерфейсе и в постоянном уведомлении (ongoing notification).

**Основная цель работы** — демонстрация использования **многопоточности** в Android-приложении, а также взаимодействия фонового потока с главным (UI) потоком и системой уведомлений.

Приложение написано на языке **Java** в среде **Android Studio**.

---

## Функциональные возможности

- ✅ Запуск таймера
- ✅ Остановка таймера
- ✅ Сброс таймера
- ✅ Отображение времени в формате: секунды + миллисекунды
- ✅ Отображение текущего времени таймера в шторке уведомлений
- ✅ Работа таймера при свернутом приложении

---

## Архитектура и основные сущности

### Activity

`MainActivity` — основная **сущность** приложения, представляющая экран пользователя.

Внутри Activity создаются и управляются все основные **объекты**:
- Элементы интерфейса (TextView, Button)
- Поток таймера
- Уведомление

---

### Поток таймера (Thread)

Для подсчета времени используется отдельный поток (`Thread`).

**Назначение потока:**
- Выполнение длительной операции (подсчёт времени)
- Предотвращение блокировки главного потока (UI)

Поток работает в цикле `while (isRunning)` и:
- Вычисляет прошедшее время
- Обновляет интерфейс и уведомление

---

### Подсчёт времени

Для получения реального времени используется метод:
```java
System.currentTimeMillis()
```

**Алгоритм:**

1. При старте запоминается время запуска (`startTime`)
2. В потоке вычисляется разница между текущим временем и временем старта
3. Полученное значение переводится в секунды и миллисекунды

> Такой подход обеспечивает более точный таймер по сравнению с использованием `sleep()`.

---

### Взаимодействие с UI-потоком

Так как обновление интерфейса разрешено только из главного потока, используется метод:
```java
runOnUiThread()
```

Он позволяет безопасно обновлять:
- TextView с текущим временем
- Содержимое уведомления

---

## Уведомления

### Тип уведомления

Используется постоянное уведомление (ongoing notification), которое:
- Отображается в шторке уведомлений
- Не удаляется свайпом
- Обновляется в реальном времени

> Уведомление существует, пока приложение находится в памяти.

### Канал уведомлений

Для Android 8+ создаётся канал уведомлений (`NotificationChannel`), необходимый для управления уведомлениями приложения.

### Разрешения

Начиная с Android 13 требуется разрешение:
```
POST_NOTIFICATIONS
```

Разрешение запрашивается у пользователя при запуске приложения.

## Основные методы MainActivity

### `startTimer()`
- Запускает фоновый поток
- Инициализирует стартовое время
- Устанавливает флаг работы таймера

### `stopTimer()`
- Останавливает выполнение потока
- Сохраняет текущее значение времени

### `resetTimer()`
- Полностью сбрасывает таймер
- Останавливает поток
- Удаляет уведомление

### `updateNotification(String timeText)`
- Создает или обновляет уведомление
- Отображает текущее время таймера

### `createNotificationChannel()`
- Создаёт канал уведомлений для Android 8+

---

## Причины выбора реализации

- Использование `Thread` позволяет наглядно продемонстрировать многопоточность
- Логика размещена в Activity для упрощения структуры
- Отказ от `Service` сделан осознанно, так как приложение не требует работы при полном закрытии
