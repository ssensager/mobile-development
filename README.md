# Currency Rates (Android, Java)

## Описание проекта
Данное Android-приложение предназначено для получения и отображения актуальных
курсов валют с использованием внешнего REST API Центрального банка Российской Федерации.

Приложение выполняет асинхронный HTTP-запрос, обрабатывает ответ в формате JSON
и отображает выбранные пользователем валюты в пользовательском интерфейсе.

Проект реализован на языке Java в среде разработки Android Studio.

---

## Цель работы
Целью работы является изучение:
- работы с внешними API;
- выполнения HTTP-запросов в Android;
- асинхронной обработки данных (многопоточность);
- парсинга JSON-данных;
- взаимодействия с элементами пользовательского интерфейса.

---

## Используемый API
Для получения курсов валют используется открытое REST API Центрального банка РФ:

https://www.cbr-xml-daily.ru/daily_json.js

Характеристики API:
- формат данных — JSON;
- не требует регистрации и API-ключей;
- предоставляет актуальные курсы валют.

---

## Функциональные возможности
- загрузка курсов валют из внешнего API;
- динамическое формирование списка доступных валют;
- выбор двух валют пользователем;
- автоматическое обновление курсов при выборе валют;
- отображение курсов в пользовательском интерфейсе.

## Основные сущности и объекты

### Activity
`MainActivity` — основная сущность приложения, отвечающая за:
- загрузку данных из API;
- обработку пользовательских действий;
- обновление интерфейса.

---

### Данные валют
```java
JSONObject valuteData


Используется как объект-хранилище, содержащий курсы всех валют,
полученные из API.

Список валют
ArrayList<String> currencyList


Коллекция, содержащая коды доступных валют (USD, EUR и др.),
используется для заполнения элементов Spinner.

Адаптер
ArrayAdapter<String>


Связывает список валют с элементами Spinner и отвечает за их отображение.

Работа с API
HTTP-запрос

Запрос выполняется через класс HttpURLConnection в отдельном потоке (Thread),
так как Android запрещает сетевые операции в главном потоке.

Многопоточность

сетевой запрос и обработка JSON выполняются в фоновом потоке;

обновление пользовательского интерфейса осуществляется в UI-потоке
с помощью runOnUiThread().

Обработка JSON

Ответ от API имеет вложенную структуру.
Для обработки используется класс JSONObject.

Данные извлекаются по следующей схеме:

Valute — объект со всеми валютами;

ключи объекта — коды валют (USD, EUR и т.д.);

поле Value — курс валюты.

Пользовательский интерфейс
Spinner

Для выбора валют используются элементы Spinner.
Список валют формируется динамически на основе данных API.

OnItemSelectedListener

Для обработки выбора валют реализован слушатель OnItemSelectedListener.
При изменении выбранной валюты автоматически обновляется отображаемый курс.

Основные методы MainActivity
loadCurrencyRates()

выполняет HTTP-запрос;

получает JSON-ответ;

формирует список валют;

сохраняет данные для дальнейшего использования.

updateRates()

извлекает выбранные валюты;

получает соответствующие курсы;

обновляет элементы интерфейса.

Разрешения

Для работы приложения требуется разрешение:

<uses-permission android:name="android.permission.INTERNET"/>

Ограничения реализации

приложение использует упрощённую архитектуру;

данные не кэшируются между запусками;

приложение ориентировано на учебное использование.

Вывод

выполняет поставленные задачи и соответствует требованиям учебного задания.
