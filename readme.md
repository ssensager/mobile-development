# AI for BJU — мобильное приложение на Android (Java)

## Описание проекта
Данное мобильное приложение предназначено для расчёта суточной нормы калорий и распределения БЖУ (белки, жиры, углеводы) на основе введённых данных пользователя.

Приложение реализовано на языке **Java** в среде **Android Studio** и использует простейшую интеллектуальную систему на основе правил (rule-based system).

## Функциональные возможности
- Ввод данных пользователя:
  - возраст
  - рост
  - вес
  - пол
  - цель питания (похудение, поддержание, набор массы)
- Проверка корректности введённых данных
- Расчёт:
  - суточной калорийности
  - белков, жиров и углеводов
- Вывод результата в удобном текстовом виде

## Используемый подход ИИ
В приложении реализована **интеллектуальная система на основе правил**.  
Алгоритм анализирует входные данные пользователя и в зависимости от выбранной цели питания адаптирует расчёт калорийности и БЖУ.

Используемые принципы:
- логические условия
- набор правил
- адаптация результата под конкретного пользователя

Данный подход относится к классу **rule-based AI** и является базовым уровнем интеллектуальных систем.

## Структура проекта
- `MainActivity.java` — пользовательский интерфейс и обработка действий
- `BjuCalculator.java` — логика интеллектуальной системы и расчётов
- `activity_main.xml` — разметка экрана приложения

## Проверка корректности данных
В приложении реализована валидация пользовательского ввода:
- проверка на пустые поля
- исключение отрицательных и нереалистичных значений
- проверка выбора пола

При ошибке пользователю выводится соответствующее сообщение.

## Используемые технологии
- Java
- Android SDK
- Android Studio
- XML (разметка интерфейса)
